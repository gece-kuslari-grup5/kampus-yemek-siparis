# Kampüs Yemek Sipariş Uygulaması

Düzce Üniversitesi Yönetim Bilişim Sistemleri (YBS) 471 - Yazılım Yönetimi dersi kapsamında, Agile/Scrum metodolojisiyle geliştirilen dönem projesidir.

## 🎯 Proje Amacı ve Kapsamı
Bu projenin temel amacı, öğrencilerin günlük yemekhane menüsünü önceden görüntüleyebilmesini, porsiyon kapasitesi dolmadan rezervasyon oluşturabilmesini, yemekhaneye geliş saatini seçebilmesini ve 'al götür / yemekhanede ye' tercihlerini yönetebilmesini sağlayan dijital bir altyapı sunmaktır.
- *Not:* Online ödeme ve bakiye yükleme işlemleri projenin bu aşamasında kapsam dışı bırakılmıştır.

## 🛠️ Kullanılan Teknolojiler ve Araçlar
- **Yönetim & Planlama:** Jira (Scrum Board, Backlog, Sprint Yönetimi)
- **Versiyon Kontrol:** GitHub (Branch stratejisi: `main`, `develop`, `feature/*`)
- **Arayüz Tasarımı:** Figma
- **Prototipleme:** HTML5, CSS3, JavaScript (VS Code)

## 📁 Proje Yapısı
- `/docs` — Sprint planlama, daily loglar ve süreç raporları
- `/assets` (veya `/design`) — Figma tasarım çıktıları, ikonlar ve görsel varlıklar
- `/src` — Arayüz ve prototip kod dosyaları
